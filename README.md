# College Network - Packet Tracer Project

## 📘 Project Overview

This project simulates a comprehensive network design for a college environment using Cisco Packet Tracer. The objective is to demonstrate a structured network topology that ensures connectivity, scalability, and security across different departments within a college campus.

## 🧱 Network Components

The simulated network includes the following elements:

- **Core Devices:**
  - Routers
  - Switches (Core, Distribution, and Access layers)

- **End Devices:**
  - Desktop PCs (for Staff, Students, Admin)
  - Servers (Web, DNS, DHCP, File)
  - Printers

- **Interconnectivity:**
  - VLAN segmentation for different departments
  - Static/Dynamic Routing (e.g., RIP, OSPF)
  - DHCP for dynamic IP assignment
  - DNS for hostname resolution

## 🏢 Departments Simulated

- **Administration**
- **Faculty/Staff**
- **Students**
- **Library**
- **Labs**
- **Server Room**

## 🛡️ Security Features

- VLANs for isolation
- Access Control Lists (ACLs) for traffic filtering
- Password protection on devices
- Port security on switches

## 🔌 Connectivity

- All devices are connected and able to communicate across departments where allowed.
- Internet simulation may be included via a cloud or external network.
- Proper addressing scheme (IPv4) and subnetting have been used.

## 📁 File Structure

- `College Network.pkt` — Main Packet Tracer file containing the complete network topology and configuration.

## ✅ How to Use

1. Open Cisco Packet Tracer.
2. Load the `College Network.pkt` file.
3. Explore device configurations by clicking on individual components.
4. Run simulations to observe data flow and connectivity.
5. Modify or extend the topology as needed.

## 🛠️ Requirements

- Cisco Packet Tracer 8.0 or later
- Basic understanding of networking concepts (TCP/IP, Subnetting, VLANs, Routing)

## 📌 Notes

- Designed for academic and demonstration purposes.
- You can customize IP addressing, VLAN IDs, and routing protocols as per institutional needs.
